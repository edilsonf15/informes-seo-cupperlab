Política de privacidad

Informes SEO · Cupperlab · Actualizado: octubre de 2026

Esta política describe cómo la aplicación Informes SEO de Cupperlab (en adelante, "la aplicación", accesible en informes.cupperlab.com) trata los datos cuando un usuario la conecta con su cuenta de Google.

1. Qué datos usamos

La aplicación solicita acceso de solo lectura a:

  • Google Analytics (ámbito analytics.readonly): métricas de tráfico y uso de los sitios web del propio usuario.
  • Google Search Console (ámbito webmasters.readonly): datos de rendimiento en búsqueda (clics, impresiones, posiciones, consultas) de los sitios verificados del usuario.
  • La dirección de correo de la cuenta conectada, solo para identificarla dentro de la aplicación.

La aplicación no modifica ninguna configuración ni dato en las cuentas de Google: el acceso es únicamente de lectura.

2. Para qué los usamos

Los datos se utilizan exclusivamente para generar informes y paneles de rendimiento SEO de los sitios web del usuario (evolución de tráfico, posiciones, palabras clave, auditoría técnica). No se usan para ningún otro fin.

3. Cómo los almacenamos

Los tokens de acceso de Google se guardan de forma cifrada en el servidor privado del usuario para poder consultar los datos cuando este genera un informe. Los informes generados se guardan en ese mismo servidor. No se almacenan datos personales de terceros más allá de las métricas agregadas necesarias para los informes.

4. Con quién los compartimos

Con nadie. Los datos no se venden, ceden ni comparten con terceros. Permanecen en el entorno privado de Cupperlab y de su cliente.

5. Uso limitado (Google API Services)

El uso de la información recibida de las APIs de Google por parte de esta aplicación se ajusta a la Política de Datos de Usuario de los Servicios de las APIs de Google, incluidos sus requisitos de Uso Limitado (Limited Use).

6. Revocar el acceso

El usuario puede desconectar la cuenta en cualquier momento desde la propia aplicación, o retirar el permiso desde la configuración de su cuenta de Google.

7. Contacto

Para cualquier duda sobre esta política: soporte@cupperlab.com.
