Términos de uso

Informes SEO · Cupperlab · Actualizado: octubre de 2026

La aplicación Informes SEO de Cupperlab es una herramienta interna de uso profesional para generar informes y análisis SEO de sitios web a partir de datos de Google Analytics y Google Search Console a los que el usuario tiene acceso legítimo.

1. Uso aceptable

El usuario se compromete a conectar únicamente cuentas y propiedades sobre las que tiene autorización, y a usar la aplicación para fines de análisis y reporte SEO de sus propios clientes o proyectos.

2. Acceso de solo lectura

La aplicación accede a los datos de Google en modo solo lectura y no realiza cambios en las cuentas conectadas.

3. Disponibilidad

La aplicación se ofrece "tal cual". Cupperlab procura su disponibilidad pero no garantiza un servicio ininterrumpido.

4. Datos

El tratamiento de datos se rige por la Política de privacidad.
